# PT-RQ35K2 / PT-RZ34K2 / PT-RZ330 — full NTCONTROL command list

Generated from Panasonic's `RQ35K2_RZ34K2 Control Commands_2508.csv` (2025-08). The owner's
note: the basic commands apply to other Panasonic models too; model-specific ones (slots, 3D,
Quad Pixel Drive, …) may answer `ERR1`/`ER401` elsewhere — verify on the target model.
The list is **not exhaustive** — e.g. the solid-colour test patterns `OTS:22`–`30` and
`OTS:51` the app sends aren't in it (see `command_reference.md` → Test pattern).

Reading the table:
- **Query** is sent as-is; the reply is shown after `→` (after the `00` prefix is stripped).
- `VXX:KEYx=+nnnnn` writes an extended variable; `QVX:KEYx` reads it back as `KEYx=+nnnnn`.
- `*` / `*****` in a command or reply is a placeholder for a value (see the min/max rows).
- A model note in parentheses appears only when support differs between the three series
  (✔ in all three is omitted). "by lens type" ranges depend on the mounted lens.
- The source's category column is misaligned (labels sit at page breaks), so categories are
  omitted; rows follow the projector's menu order. Grep by command key or function name.
